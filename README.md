# opinion-campaign-networks

Semester project for **SMAII, Redes Complejas Multicapa** (Multilayer Complex Networks).

This project models how opinion evolves in a connected population when a sustained
external stimulus appears — for example, a marketing or political campaign. The goal is
to characterize when opinion converges, when it polarizes, and when the campaign
backfires, in order to anticipate whether launching it is worthwhile. The starting point
is bounded-confidence models with stubborn agents and algorithmic bias, with a possible
second layer of observable behavior.
